The crux: an AI scanner that finds where data goes missing

In climbing, the crux is the hardest move on a route, the one that decides whether you top out. Mine right now is my newest project as a staff engineer: a scanner that reads ingestion pipelines and their databases, finds the gaps where records can be lost, ranks the fixes, and opens the pull request.

  1. 1

    Review

    Haiku + Opus

    Agents run four-lens workflow reviews over the pipeline code, flagging every place a record could drop.

  2. 2

    Trace upstream

    Opus

    Follows each gap upstream, reading the database itself, to find where the loss really starts.

  3. 3

    Measure downstream

    Opus

    Writes the impact analysis and a Sankey of what is lost, so the fix order is obvious to anyone.

  4. 4

    Fix

    Pull request

    The highest-impact gaps come back as pull requests, ready for review.
